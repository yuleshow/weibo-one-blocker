# Weibo One-Click Blocker

一键批量拉黑微博用户的 Chrome/Edge 浏览器扩展。

## 功能

- 批量输入用户 UID，一键拉黑
- 支持直接粘贴用户主页链接，自动提取 UID
- 可调节请求间隔，避免触发频率限制
- 实时显示拉黑进度和结果

## 安装

1. 打开 Chrome/Edge 浏览器，进入 `chrome://extensions/`（Edge 用 `edge://extensions/`）
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本项目文件夹

## 使用

1. 先登录 [weibo.com](https://weibo.com)
2. 点击浏览器工具栏的扩展图标
3. 在文本框中输入要拉黑的用户 UID（每行一个），支持以下格式：
   - 纯数字 UID：`1234567890`
   - 用户主页链接：`https://weibo.com/u/1234567890`
4. 设置请求间隔（建议 ≥ 1000ms）
5. 点击 **🚫 一键拉黑**

## 获取用户 UID

- 打开用户主页，URL 中 `/u/` 后面的数字就是 UID
- 例如 `https://weibo.com/u/1234567890` 中 UID 为 `1234567890`

## 注意事项

- 使用前必须已登录 weibo.com
- 请合理设置请求间隔，避免频繁操作导致账号受限
- 本扩展仅在本地运行，不会上传任何数据
